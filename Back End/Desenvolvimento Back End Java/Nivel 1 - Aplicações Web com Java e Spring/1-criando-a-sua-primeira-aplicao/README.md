# ☕ Trilha Java Back-End — Alura
## Nível 1: Aplicações Web com Java e Spring
### 📌 Módulo 1: Criando a Sua Primeira Aplicação

Este repositório reúne as anotações, conceitos, desafios e exercícios práticos desenvolvidos ao longo do **Módulo 1** da formação de **Desenvolvimento Back-End em Java** na Alura. 

> 🎯 **Status do Módulo:** Todos os desafios e exercícios propostos pelos instrutores foram devidamente implementados, testados e concluídos, consolidando os conhecimentos teóricos na prática.

---

## 📚 Conteúdo Detalhado por Aula & Exercícios

### 🚀 Aula 01: Configuração do Ambiente e Primeiro Programa
* **Instalação e Ferramentas**: Configuração do ambiente de desenvolvimento com o **JDK 17** e navegação na IDE **IntelliJ IDEA**.
* **Arquitetura do Ecossistema Java**:
  * **JVM (*Java Virtual Machine*)**: A Máquina Virtual responsável por executar o *bytecode*.
  * **JRE (*Java Runtime Environment*)**: Ambiente de Execução que fornece as bibliotecas padrão para a execução dos programas.
  * **JDK (*Java Development Kit*)**: Kit de Desenvolvimento responsável por compilar o código-fonte (`.java`) em *bytecode* (`.class`).
* **Primeiro Programa**: Criação, compilação e execução da classe inicial para exibir o clássico `"Alô Mundo!"` no console.
* **Desafios Concluídos**: Configuração bem-sucedida do ambiente e execução de programas simples via linha de comando/IDE.

---

### 🔢 Aula 02: Variáveis, Tipos de Dados e Casting
* **Variáveis**: Armazenamento e manipulação de valores na memória do computador.
* **Tipos Primitivos**:
  * **Inteiros**: `byte`, `short`, `int`, `long`
  * **Ponto Flutuante**: `float`, `double`
  * **Caractere**: `char` (armazena um único caractere)
  * **Lógico**: `boolean` (`true` ou `false`)
* **Textos**: Representação e manipulação de cadeias de caracteres utilizando a classe `String`.
* **Casting de Tipos**: Conversão explícita e implícita de valores para resolver incompatibilidades de tipos em cálculos e atribuições.
* **Desafios Concluídos**: Exercícios práticos de conversão de temperaturas (Celsius para Fahrenheit), cálculo de descontos, e operações com valores usando casting.

---

### 🔀 Aula 03: Controle de Fluxo e Leitura de Dados
* **Estruturas Condicionais**: Tomada de decisões na aplicação utilizando `if`, `else if`, `else` e `switch`.
* **Operadores Relacionais**: Comparações lógicas (`==`, `!=`, `>`, `<`, `>=`, `<=`).
* **Entrada de Dados**: Leitura de dados informados pelo usuário via teclado utilizando a classe `Scanner`.
* **Estruturas de Repetição**: Criação de laços iterativos utilizando `for` e `while`.
* **Desafios Concluídos**: Implementação do clássico *Jogo da Adivinhação* (número secreto com contagem de tentativas) e calculadoras interativas com validação de entrada de dados.

---

### 🏦 Aula 04: Projeto Prático – Sistema Bancário
* **Aplicação Consolidada**: Desenvolvimento de uma aplicação completa de terminal simulando um sistema bancário.
* **Integração de Conceitos**:
  * Aplicação de lógica de programação estruturada.
  * Manipulação de variáveis e tipos de dados para controle de conta e saldo.
  * Estruturas condicionais e de repetição para navegação via menu interativo.
  * Leitura e validação contínua de dados fornecidos pelo usuário.
* **Desafios Concluídos**: Construção e validação do fluxo do menu do sistema bancário (consultar saldos, efetuar transferências e receber depósitos com tratamento de erros).

---

## 🚀 Como Executar os Projetos

1. Certifique-se de possuir o **JDK 17** instalado em sua máquina.
2. Clone o repositório e abra o projeto no **IntelliJ IDEA**.
3. Navegue até o diretório `src/` para encontrar os arquivos dos módulos, desafios e o projeto do sistema bancário.
4. Execute a classe contendo o método `main` correspondente ao exercício ou aplicação desejada.
